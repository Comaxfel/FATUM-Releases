# FATUM Releases

Публичный канал обновлений FATUM VTT.

Этот репозиторий предназначен только для автоматического обновлятора FATUM. Исходный код проекта здесь не публикуется.

## Stable channel

- `latest.json` — описание актуальной версии и доступных путей обновления.
- `patches/` — дельта-пакеты между версиями.

Обновлятор FATUM проверяет SHA-256 каждого пакета перед установкой и не должен изменять пользовательские данные и overrides.

Текущая стабильная версия канала: **1.7.13**.
